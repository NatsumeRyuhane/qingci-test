# AI collaboration log

Deliverable C of the assignment is the record of how this project was built with AI assistance.
That process is the part of the assignment weighted most heavily ([requirements](../requirements.md)).

## What goes here

- **Session logs:** exported transcripts of AI coding sessions, one file per session, named
  `YYYY-MM-DD-<topic>.md` (or the tool's native export format).
- **Not** a substitute for the decision log. Decisions still go in [decisions.md](../decisions.md),
  and work items still go in GitHub issues. Logs show *how* we got there.

## Before committing a log

Raw transcripts include tool output, so review every log before adding it:

- Remove secrets (API keys, tokens) and personal details such as email addresses and local
  usernames in paths.
- Trim large excerpts of the sample data to short quotes (see [data/README.md](../../data/README.md)).
- Keep the conversation itself intact. Don't rewrite what was said.
