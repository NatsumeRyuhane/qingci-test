# data/

| Directory | Contents | Committed? |
|---|---|---|
| `raw/` | The original sample workbook, exactly as received | **No** |
| `interim/` | Parsed / cleaned threads produced by the ingest step | **No** |
| `processed/` | Knowledge base and indexes built from `interim/` | **No** |

Only this README and the `.gitkeep` files are tracked. Everything else is regenerated by scripts.

## Getting the sample data

The workbook `脱敏数据2026.2.10.xlsx` ("de-identified data, 2026-02-10") was provided by the client
with the assignment ([docs/requirements.md](../docs/requirements.md)). It is not in this repository.
Ask the repository owner for a copy and place it at:

```
data/raw/脱敏数据2026.2.10.xlsx
```

## Rules

- The data is de-identified but still belongs to the client. **Never commit it**, and never paste
  more than a short excerpt into issues, PRs, commit messages or logs.
- Sending it to the configured LLM provider is part of the product and is fine. Don't upload it to
  any other external service (pastebins, public notebooks, other AI tools' file uploads).
- What the data looks like: see [docs/data.md](../docs/data.md).
